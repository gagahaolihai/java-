### `ContactRepository` 接口（**今天的重点**）

```java
public interface ContactRepository {
    Contact save(Contact contact);                 // id 为 null 则新增，否则更新
    Optional<Contact> findById(Long id);
    List<Contact> findAll();
    List<Contact> search(String keyword, String group);
    boolean deleteById(Long id);
    boolean existsByPhone(String phone, Long excludeId);   // excludeId 用于「修改时排除自己」
    long count();
    void flush() throws IOException;               // 落盘
    void load() throws IOException;                // 启动时加载
}
```

`FileContactRepository` 实现要点：
- 内存里用 `LinkedHashMap<Long, Contact>` 做主存，`flush()` 时整体写 CSV
- `AtomicLong` 或 `max(id)+1` 生成 ID
- `load()` 时文件不存在不能抛异常（首次运行）
- 所有 IO 异常包装成 `BusinessException`，**保留 cause**

### 手机号/邮箱校验（正则入门）

```java
public final class Validators {
    private static final Pattern PHONE = Pattern.compile("^1[3-9]\\d{9}$");
    private static final Pattern EMAIL = Pattern.compile("^[\\w.+-]+@[\\w-]+\\.[\\w.]+$");
    public static boolean isPhone(String s) { return s != null && PHONE.matcher(s).matches(); }
    public static boolean isEmail(String s) { return s == null || s.isBlank() || EMAIL.matcher(s).matches(); }
    // 注意：邮箱允许为空（选填），空串要放行 —— 写成单元测试验证
}
```

## 四、六个技术点的落地对照（今天要能指着代码说）

| W1 学的 | 在通讯录里用在哪 |
|---|---|
| 接口与多态 | `ContactRepository` 接口 + `FileContactRepository` 实现，`Service` 只依赖接口 |
| 泛型 | 方法返回 `Result<T>` 或 `Optional<T>`，`ConsoleView` 里有 `List<Contact>` 处理 |
| 集合 | `LinkedHashMap` 存主数据（保持插入顺序）、`TreeMap` 做分组统计排序、`ArrayList` 存检索结果 |
| Stream | 检索用 `filter` + `sorted`；分组统计用 `groupingBy` + `counting` |
| 异常 | `BusinessException` 家族；IO 异常包装且保留 cause；`AutoCloseable` 用在一处（提示：可以给 `ConsoleView` 做个自动关闭的输入流包装） |
| IO | CSV 读写、`Files.newBufferedWriter` + `try-with-resources`、`Path` 操作 |
