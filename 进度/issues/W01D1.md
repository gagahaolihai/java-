### 第 1 步：`Shape` 接口

```java
public interface Shape {
    double PI = 3.141592653589793;      // 接口字段默认 public static final
    double area();
    double perimeter();
    default String describe() {          // 默认方法：子类可不实现
        return String.format("%s 面积=%.2f 周长=%.2f", name(), area(), perimeter());
    }
    String name();
    static Shape of(String type) { /* 简单工厂，可选 */ return null; }
}
```
**思考**：为什么接口里放 `PI` 会被人诟病？（提示：常量接口反模式）

### 第 2 步：`AbstractShape` 抽象类

```java
public abstract class AbstractShape implements Shape {
    private final String name;                 // final + 构造器赋值 = 不可变
    protected AbstractShape(String name) { this.name = name; }
    @Override public String name() { return name; }
    @Override public String toString() { return describe(); }
    public abstract double area();             // 可以不重复声明，体会「抽象类不必实现接口全部方法」
}
```

### 第 3 步：三个具体形状

| 类 | 构造参数 | 校验规则 |
|---|---|---|
| `Circle` | `radius` | `radius > 0`，否则抛 `InvalidShapeException` |
| `Rectangle` | `width, height` | 两者 `> 0` |
| `Triangle` | `a, b, c` | 三边 `> 0` **且** 任意两边之和大于第三边（三角形不等式） |

`InvalidShapeException` 先这样写（D6 会重构它）：

```java
public class InvalidShapeException extends IllegalArgumentException {
    public InvalidShapeException(String message) { super(message); }
}
```

### 第 4 步：`ShapeCalculator`

```java
public class ShapeCalculator {
    public static double totalArea(List<Shape> shapes) { ... }
    public static List<Shape> sortedByAreaDesc(List<Shape> shapes) { ... }
    public static Map<String, List<Shape>> groupByType(List<Shape> shapes) { ... }
    public static Map<String, Double> areaByType(List<Shape> shapes) { ... }
    public static Optional<Shape> largest(List<Shape> shapes) { ... }
}
```

要求：
- `sortedByAreaDesc` 用 `Comparator.comparingDouble(Shape::area).reversed()`
- `groupByType` 用 `Collectors.groupingBy(Shape::name)`
- `areaByType` 用 `groupingBy` + 下游 `summingDouble`
- 入参为 `null` 或空集合时不能抛 NPE，返回空结果
