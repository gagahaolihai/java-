### 第 3 步：大文件读取 —— 内存与耗时实测（**今天的核心实验**）

```java
public class BigFileReader {
    // 方案 A：一次性全读进内存（危险）
    public static long readAll(Path file) throws IOException {
        List<String> lines = Files.readAllLines(file, StandardCharsets.UTF_8);
        return lines.size();
    }

    // 方案 B：流式逐行（推荐）
    public static long streamLines(Path file) throws IOException {
        try (Stream<String> lines = Files.lines(file, StandardCharsets.UTF_8)) {
            return lines.count();
        }
    }

    // 方案 C：BufferedReader 手动逐行
    public static long buffered(Path file) throws IOException {
        long count = 0;
        try (BufferedReader r = Files.newBufferedReader(file, StandardCharsets.UTF_8)) {
            while (r.readLine() != null) count++;
        }
        return count;
    }
}
```

### 第 4 步：缓冲流 vs 无缓冲流写入对比

```java
public class BufferBenchmark {
    static final int N = 200_000;

    public static long writeNoBuffer(Path f) throws IOException {
        long t = System.currentTimeMillis();
        try (FileWriter w = new FileWriter(f.toFile())) {          // 无缓冲
            for (int i = 0; i < N; i++) w.write("line " + i + System.lineSeparator());
        }
        return System.currentTimeMillis() - t;
    }

    public static long writeBuffered(Path f) throws IOException {
        long t = System.currentTimeMillis();
        try (BufferedWriter w = new BufferedWriter(new FileWriter(f.toFile()), 8192)) {
            for (int i = 0; i < N; i++) { w.write("line " + i); w.newLine(); }
        }
        return System.currentTimeMillis() - t;
    }
}
```
预期：**缓冲流快 10–100 倍**。把实测倍数写进笔记，并解释原因（每次 `write` 都是一次系统调用 vs 攒满 8KB 才落盘）。

### 第 6 步：NIO 概念 —— 只做了解，别陷进去

写一段把文件复制两块乐高：
```java
public static void copyWithChannel(Path src, Path dst) throws IOException {
    try (FileChannel in = FileChannel.open(src, StandardOpenOption.READ);
         FileChannel out = FileChannel.open(dst, StandardOpenOption.CREATE, StandardOpenOption.WRITE)) {
        ByteBuffer buf = ByteBuffer.allocateDirect(8192);      // 堆外内存
        while (in.read(buf) != -1) {
            buf.flip();          // 切换成读模式：limit = position, position = 0
            out.write(buf);
            buf.clear();         // 切换成写模式
        }
    }
}
```
**写进笔记**：`flip()` / `clear()` / `rewind()` 分别做了什么？为什么 `ByteBuffer` 需要这些状态切换？（这是 NIO 最容易搞混的地方）
