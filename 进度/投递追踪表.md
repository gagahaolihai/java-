## 渠道清单

| 渠道 | 特点 | 使用建议 |
|---|---|---|
| BOSS 直聘 | 反馈最快，可直接和 HR/技术聊 | 主战场，每天打招呼 20+，简历附件用 PDF |
| 牛客网 | 校招/内推信息集中，有面经 | 搜同岗位面经，反推复习重点 |
| 拉勾 | 互联网岗位多 | 补充 |
| 公司官网/公众号 | 大厂校招正式渠道 | 提前批优先 |
| GitHub / 开源社区招聘 Issue | 小而美公司 | 附带仓库链接命中率高 |

## 复盘规则

**每场面试当天必须写** `笔记/07-八股与面试/面试复盘-MMDD-公司.md`：

1. 面试流程与时长
2. 被问到的每个问题（原话记下来）
3. 我当时怎么答的（诚实）
4. 标准答案 / 更好的答法
5. 暴露的知识盲区 → 加进复习清单

> 前 3 场面试当练手，不要挑最想去的公司。第 4 场开始命中率会明显上升。
